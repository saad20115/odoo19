# HR Attendance Quick Return Detection

## الوصف
هذا الـ module يكتشف تلقائياً الحالات التي يقوم فيها الموظف بتسجيل خروج ثم دخول خلال أقل من دقيقة.

## المميزات
- ✅ كشف تلقائي للعودة السريعة
- ✅ عرض الوقت بالدقائق بين التسجيلات
- ✅ فلتر للبحث عن الحالات المشبوهة
- ✅ واجهة عربي/إنجليزي

## التثبيت
1. ضع المجلد في مسار addons
2. أعد تشغيل Odoo
3. قم بتحديث قائمة التطبيقات
4. ثبت الـ module

## الاستخدام
بعد التثبيت، ستجد:
- حقل "عودة سريعة" في قائمة الحضور
- فلتر "حالات العودة السريعة" في البحث
- معلومات إضافية في نموذج الحضور

## الإصدار
- Odoo: 17.0
- Version: 1.0.0
